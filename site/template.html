Code you can read aloud.

Prose is a small programming language made of plain English words. It compiles to ordinary JavaScript, so it runs anywhere JavaScript runs and works alongside the code you already have.

One function, said out loud.

without comes from Datums, a personal log with lists of pinned and hidden charts. It returns a list with one chart taken out, comparing text keys because two separate objects can describe the same chart.   • The symbols that stay

    The comma separates the parameters, the colon reads filter from refs, and != compares. Everything else is a word. The underscore in chart_key is part of the name, so it isn't counted.

  • Why there are no parentheses

    A call takes every comma after it, and a call with one argument finishes before an operator. So chart_key item != chart_key ref compares two calls with nothing to group. When a call should stop sooner, parentheses end it: (add 1, 2), 3.

  • What the Prose leaves out

    The TypeScript says what refs holds, and the Prose doesn't. Those types are {{without_type_symbols}} of its {{without_ts_symbols}} symbols, and they do a job: prose check lets without 1, 2 through here. Add them back with as and it reports the mistake. Bring your libraries. Keep your build.

Prose calls JavaScript methods, creates JavaScript objects, and imports from JavaScript and TypeScript files. Its arrays and objects are JavaScript's own, so libraries that compare them by identity, like React, see the same values.

A Vite plugin compiles .prose files as they're imported, in development, in builds, and in Vitest.

Types when you want them.

Add as and giving where they help, and prose check checks them with your project's TypeScript. Prose writes the declaration file for you, so TypeScript that imports your module is checked too. Leave them out and everything still runs.

Comments above a declaration become its documentation.

Get started.

Prose is young, and it's still changing. It's free and open source under the MIT license. The repository has the compiler and command-line tool, a Vite plugin, a VS Code extension, example programs, and {{test_summary}}.

You need Node.js 20.19 or newer. There is nothing else to install.

  1. Get the code

    Clone the repository.

    git clone https://github.com/travisk-codes/prose-lang.git

  2. Run the tour

    One program that uses every feature, section by section.

    cd prose-lang
node bin/prose.js examples/tour.prose --run

  3. Write your own

    Save a .prose file and run it the same way, or import it from a Vite project.
