A programming language

Code you can read aloud.

Prose is a small programming language made of plain English words. It compiles to ordinary JavaScript, so it runs anywhere JavaScript runs and works alongside the code you already have.

Features

Words where other languages use symbols.

Braces, semicolons, and arrows become words you already know. What's left is short enough to read in one breath.

Plain words for decisions

is stores a value and = compares. An if can fill in a value or run a line.

{{f_words}}

Loops that name what they visit

for each walks lists, text, and maps, and takes pairs apart into names.

{{f_loops}}

Functions without the punctuation

Say what a function takes. Call it by writing the values after its name.

{{f_functions}}

Missing values, said out loud

Reading through something missing stops with the line number, unless you write maybe.

{{f_maybe}}

Text that counts like a person

Positions start at 1, and an emoji is one character. This prints {{f_positions_output}}.

{{f_positions}}

Functions are values

Hand a function to any JavaScript method that wants one, written on one line or indented below.

{{f_values}}

Works with JavaScript

        
Bring your libraries. Keep your build.

        
Prose calls JavaScript methods, creates JavaScript objects, and imports from JavaScript and TypeScript files. Its arrays and objects are JavaScript's own, so libraries that compare them by identity, like React, see the same values.

        
A Vite plugin compiles .prose files as they're imported, in development, in builds, and in Vitest.

      

      

        next-day.prose
        
{{interop_prose}}

        vite.config.ts
        
import prose from 'prose-lang/vite'

export default defineConfig({
  plugins: [prose({ declarations: true })],
})

      

    

  


  

    

      

        
Types

        
Types when you want them.

        
Add as and giving where they help. Prose writes the TypeScript declaration file for you, so TypeScript that imports your module is fully checked. Leave them out and everything still runs.

      

      
    

  


  

    

      

        
Errata

        
A compiler that proofreads.

        
Mistakes come back with their line number and a sentence about what to do. These are the compiler's own words.
